🔄 REQUEST LIFECYCLE
─────────────────────────────────────────────────────────────────────
1. Requester creates request
   └─ System stores with PENDING status

2. Approvers notified (polling every 5s)
   └─ Request appears in approval dashboard

3. Each approver votes
   ├─ If votes in favor: +1 to currentApprovals
   └─ If votes against: request marked REJECTED

4. Threshold evaluation
   ├─ If currentApprovals >= required: Status = APPROVED ✅
   └─ If majority rejects: Status = REJECTED ❌

5. On-chain execution (future)
   └─ Smart contract executes approved actions
