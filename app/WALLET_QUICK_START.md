# 🚀 Wallet Quick Start - 60 Seconds to Connected!

## ⚡ Super Fast Setup

### Step 1: Install Phantom (30 seconds)
1. Visit: https://phantom.app/
2. Click "Download"
3. Add to your browser
4. Create wallet (follow prompts)
5. **SAVE YOUR RECOVERY PHRASE!** 🔐

### Step 2: Connect to Solar Winds (10 seconds)
1. Open Solar Winds Asset Manager
2. Click blue "Connect Wallet" button (top-right)
3. Phantom popup appears
4. Click "Connect" ✅

### Step 3: Get Test SOL (20 seconds)
1. Click your wallet button
2. Click "Copy Address"
3. Visit: https://solfaucet.com/
4. Paste address
5. Click "Airdrop"
6. Get free SOL! 🎉

## 🆘 Quick Troubleshooting

**Problem**: Button doesn't work  
**Fix**: Install Phantom, unlock wallet, refresh page

**Problem**: Balance is 0  
**Fix**: Get devnet SOL from faucet (link above)

**Problem**: Won't auto-connect  
**Fix**: Check "Trust this site" in Phantom settings
