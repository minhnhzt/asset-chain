# Add Asset - User Guide

## 🚀 Quick Start

### How to Add a New Asset (3 Simple Steps)

#### Step 1: Navigate to Add Asset
**Option A:** Click "Add Asset" in the sidebar
**Option B:** Go to "All Assets" page and click "Add Asset" button in the top-right

#### Step 2: Fill in Asset Information
**Required Fields (marked with *):**
- Asset Name (e.g., "MacBook Pro 16")
- Category (select from dropdown)

**Optional Fields:**
- Description, Serial Number, Manufacturer, Model
- Purchase Value, Purchase Date, Warranty Expiry
- Location, Assigned To
- Additional Notes
- Asset Photo

#### Step 3: Mint on Blockchain
Click the **"Mint Asset on Blockchain"** button and wait ~10 seconds.

✅ **Done!** Your asset will automatically appear in the Assets list.

## 💡 Tips & Best Practices

### For Accurate Records:

✅ **Always include serial numbers**
- Helps with warranty claims
- Required for insurance
- Makes asset tracking easier

✅ **Upload photos**
- Visual identification
- Document condition
- Useful for disputes

✅ **Set warranty expiry dates**
- Get reminders before expiry
- Plan replacements
- Track support eligibility

✅ **Assign locations immediately**
- Know where everything is
- Easier inventory audits
- Faster check-in/check-out

### For Efficiency:

✅ **Use consistent naming**
- "MacBook Pro 16" not "mbp 16" or "laptop"
- Helps with searching
- Clearer reports

✅ **Fill purchase values**
- Needed for depreciation
- Insurance requirements
- Budget tracking

✅ **Keep notes updated**
- Document issues
- Track modifications
- Remember important details

### For Compliance:

✅ **Document purchase dates**
- Required for tax purposes
- Depreciation calculations
- Warranty tracking

✅ **Use accurate values**
- Needed for insurance claims

- Financial audits

## ❓ Frequently Asked Questions

### Q: What if I make a mistake?
**A:** Currently, you'll need to delete and recreate the asset. Edit functionality is coming soon.

### Q: Can I add multiple assets at once?
**A:** Not yet. Bulk CSV import is planned for a future update.

### Q: What happens if the minting fails?
**A:** You'll see an error message. Check your internet connection and try again. Your form data is preserved.

### Q: Is the blockchain transaction real?
**A:** In the current version, it's simulated. Real Solana integration is coming in production release.

### Q: How much does it cost?
**A:** Currently free (simulation). Real blockchain: ~$0.0003 per asset on Solana devnet.

### Q: Can I delete an asset?
**A:** Delete functionality is coming in a future update.

### Q: Where is my data stored?
**A:** Currently in browser memory (lost on refresh). Backend API and database coming soon.

### Q: Can I edit an asset after creation?
**A:** Edit functionality is planned for a future update.

## 🐛 Troubleshooting

### Problem: "Add Asset" button doesn't work
**Solution:** Make sure you're on the Assets page, not another page.

### Problem: Form won't submit
**Solution:** Check that you've filled in the required fields (Name and Category).

### Problem: Minting takes too long
**Solution:** Wait up to 15 seconds. If still processing, refresh page and try again.

### Problem: Asset doesn't appear in list
**Solution:** 
1. Make sure minting completed successfully
2. Check if you're on the Assets page
3. Try refreshing the page
4. Clear search/filter settings

### Problem: Can't upload image
**Solution:**
1. Make sure it's an image file (JPG, PNG)
2. Try a smaller file (<5MB)
3. Check browser console for errors
